# AIXAM Teacher Agent Documentation

## Overview
The Teacher Agent is a sophisticated, LangGraph-based conversational AI designed to assist educators in curriculum creation, assignment delivery, and mass-grading workflows. Built to reduce administrative overhead, the Teacher Agent is context-aware and deeply integrated with the AIXAM internal services and Google Classroom.

## Architecture & Lifecycle

1. **Routing and Instantiation (`ChatBot.py`)**:
   When an authenticated user with `"role": "teacher"` initiates a chat, the system instantiates the `TeacherAgent`. 
2. **LangGraph State Map (`teacher.py`)**:
   The `TeacherAgent` leverages a StateGraph architecture passing around a `TeacherState` heavily utilizing stateful dictionaries for tasks. 
3. **Orchestrator Execution**:
   - The initial LLM evaluates the user context and generates a precise JSON array of tasks (`plan_tasks` Tool).
   - The state transitions to the `orchestrator` node which iteratively executes each specialized node logic (e.g. `_generate_assignment`, `_grade_submissions`).
4. **Structured Yielding**:
   Any database outputs generated by the sub-nodes (like standard Assignments or Graded student lists) are piped back through the `ChatBot` layer natively as dictionary objects so the React UI can dynamically render comprehensive tables instead of forcing the teacher to copy/paste text.

## Core Capabilities

### 1. Assignment Generation
The agent can dynamically generate full assignments based on the current context (`study_materials` / conversational memory). It generates robust JSON structured schemas containing Title, Descriptive Instructions, and Deadline.

### 2. Google Classroom Integration
Through `ClassroomService.py`, the Teacher Agent has seamless two-way bind capabilities to Google:
* **Post Assignments**: Pushes newly structured assignments natively to chosen classroom domains.
* **Fetch Submissions**: Hooks incoming submissions and student rosters dynamically.

### 3. Automated Batch Grading
Teachers can ask the agent to grade all retrieved Google Classroom assignments against a predefined Rubric or uploaded solutions. The agent processes inputs asynchronously, returning a structured list of students and their assigned scores/feedback.

### 4. Specialized Quiz Generation
Unlike Student practice quizzes, a Teacher-Generated Quiz creates hardened MCQ sets that append the required **Explanation** and **Points (Rubric)** to every single question, storing the official Answer Key quietly in `core_quiz` to be utilized for grading.

### 5. Document & Slides Export
The teacher can extract existing generated data and have the agent build completely formatted Markdown, `.docx`, `.pptx`, or `.pdf` files. Using the `DocumentWriter` utility, the Agent orchestrates direct binary file delivery natively through the chat stream.
